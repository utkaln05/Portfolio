# **App Name**: Analystic Pro

## Core Features:

- AI Experience Strategist Tool: A sophisticated AI-powered tool that allows recruiters to query a dedicated large language model about Utkal's specific data analyst projects and professional achievements.
- Dynamic Glassmorphic Showcase: A visual project hub with transparent glass elements showcasing Selenium automation tools, Power BI dashboards, and Python scrapers.
- Skill Proficiency Engine: Modern graphical skill markers visualizing technical strengths in SQL, Pandas, NumPy, and automation engineering with subtle load animations.
- Responsive Professional Timeline: An interactive vertical timeline charting the progress through internships, education, and professional freelance milestones.
- Instant Access Resume Module: A dedicated section featuring a direct PDF preview and immediate resume download buttons optimized for recruitment screening workflows.
- Multi-Channel Outreach Interface: Integrated communication center providing direct connection paths to professional profiles like LinkedIn and GitHub via modern contact fields.

## Style Guidelines:

- Primary color: Deep Royal (#5a67d8) for a refined sense of technical logic and authority.
- Background color: Navy Eclipse (#0f111a), a desaturated indigo-tinted dark shade that highlights modern glassmorphism components.
- Accent color: Sky Horizon (#4299e1) utilized to draw attention to interactive elements and calls-to-action with strong contrast.
- A clean font pairing using 'Space Grotesk' for impactful, modern headlines and 'Inter' for clear, objective body text.
- Minimalist premium layout utilizing wide margins and layered glass-effect cards to organize complex technical data elegantly.
- Silky-smooth entrance transitions for portfolio blocks and staggered animations on list items for a professional narrative feel.
- Thin-line vector icons specifically representing core tools such as Python, Power BI, and Selenium for visual shorthand.
